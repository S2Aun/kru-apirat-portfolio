# เว็บไซต์รายงานผลการปฏิบัติงานตามข้อตกลง วPA (Performance Agreement)
**นายอภิรัตน์ เสาวภาคย์รัตนชาติ (ครูอั้น)**  
ตำแหน่ง ครู วิทยฐานะครูชำนาญการ (ยื่นขอรับการประเมินวิทยฐานะชำนาญการพิเศษ)  
กลุ่มสาระการเรียนรู้วิทยาศาสตร์และเทคโนโลยี (คอมพิวเตอร์ / วิทยาการคำนวณ)  
โรงเรียนวันอาสาพัฒนา 2520 สังกัดสำนักงานเขตพื้นที่การศึกษาประถมศึกษานครราชสีมา เขต 4  
ปีงบประมาณ พ.ศ. 2569

---

## 🌟 จุดเด่นของเว็บไซต์
1. **ดึงข้อมูลจริงครบ 100%:** จากเอกสารแบบข้อตกลงในการพัฒนางาน (PA 1/ส) ปี 2569 ของคุณครู ทั้งชั่วโมงสอน 24 ชม., ภาระงานโรงเรียน 16 ชม., ประเด็นท้าทาย Active Learning 5E "ด๊ะดาดของดี...ดินด่านเกวียน", และ 15 ตัวชี้วัด 3 ด้าน
2. **คลังเกียรติบัตร 126 ใบในตัว:** แสดงรายการเกียรติบัตรและวุฒิบัตรจริงที่มีในเครื่อง พร้อมระบบค้นหาและแยกประเภทอัตโนมัติ
3. **ระบบกล่องใส่รูปภาพอัจฉริยะ (Interactive Image Placeholders):** ทุกตัวชี้วัดและประเด็นท้าทาย มีกล่องใส่ภาพพร้อมระบุชัดเจนว่าต้องใส่ภาพอะไร และเมื่อกดคลิกจะบอกตำแหน่งโฟลเดอร์ในเครื่อง (`G:\ไดรฟ์ของฉัน\วิทยฐานะ อั้น\Pic\...`) พร้อมปุ่มเปิด Google Drive ทันที
4. **ดีไซน์ระดับโมเดิร์น Glassmorphism:**
   - รองรับโหมดสว่าง (Light Mode) และโหมดมืด (Dark Mode)
   - Responsive 100% เปิดบนมือถือ, iPad, Tablet ของกรรมการประเมินได้อย่างสวยงาม
   - ปุ่มพิมพ์รายงาน / Save PDF ที่ตัดเมนูส่วนเกินออกให้อัตโนมัติ

## 🚀 วิธีการเปิดใช้งาน

### 1. เปิดดูผ่าน Browser ในเครื่องคอมพิวเตอร์
- ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari, Firefox) ได้ทันที

### 2. การนำรูปภาพผลงานมาใส่
- นำไฟล์ภาพไปวางไว้ในโฟลเดอร์ `G:\ไดรฟ์ของฉัน\วิทยฐานะ อั้น\Pic` ตามหมวดหมู่ที่สร้างไว้
- เมื่อต้องการนำภาพมาแสดงบนหน้าเว็บ สามารถระบุ path ของภาพในแท็ก `<img>` แทนที่กล่อง `.img-placeholder` ในไฟล์ `index.html` ได้อย่างง่ายดาย

### 3. การเผยแพร่ออนไลน์ (ส่งลิงก์ให้กรรมการประเมิน)
- **GitHub Pages:** นำโฟลเดอร์ `pa-website` ไปสร้าง Repository บน GitHub แล้วเปิดใช้งาน GitHub Pages ฟรี
- **Vercel / Netlify:** ลากโฟลเดอร์ `pa-website` ไปวางบน Vercel หรือ Netlify เพื่อรับ URL เว็บไซต์ฟรีตลอดชีพ
- **Google Sites:** สามารถนำลิงก์เว็บไซต์ หรือโค้ด iframe ไปฝังในหน้า Google Sites ได้
